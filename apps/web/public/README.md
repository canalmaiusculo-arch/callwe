# Static assets

Coloque aqui arquivos estáticos servidos diretamente:

- `favicon.ico` — ícone do site
- `ring.mp3` — som de toque quando chega chamada no painel do atendente
  - Sugestão: baixe um ringtone livre de direitos (ex: https://notificationsounds.com/notification-sounds)
  - Arquivo pequeno (<100KB) em formato MP3
